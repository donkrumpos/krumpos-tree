## 1. Brest (in-page POST technique, as in s8)

- Session URL pattern unchanged: `…/4DCGI/Web_RegistreArt<COTE>/<session>`; the session id comes from any link on the home page. GG468 = 136 views, GG469 = 150, GG482 = 151. All of a register's views can be generated in one fire-and-forget loop, then curled in ~1 min.
- **Finding pages quickly:** crop the top 450 px of each view (left and right page) into a strip, stack 16–25 per image to map year + first surname per view, then montage only the name columns (left 55% of each page, 470 px wide, four pages per image). This took about 25 image reads for 20 years of P and G sections.
- **GG468 map (1690–98, two pages per view, page no. = view×2 − 2):** 1691 = views 43–54 (P = 52; G = 46R–47); 1692 = 54R–65 (G = 57R–58, P = 62R–63); 1693 = 65R–80 (G = 69R–70, P = 76R–77); 1694 = 80R–92 (G = 83R–84, P = 89R–90); 1695 = 92R–101 (G = 95R–96, P = 99R–100); 1696 = 102–113 (G = 105R–106, P = 110R–111); 1697 = 114–126 (G = 117R–118, P = 123R–125); 1698 = 126R–136 (G = 129–130L, P = 134R–135L). - WikiTree Normandin-304 = Louise Normandin → Bodoh (b. Beloeil 4 Jul 1817, d. Bear Creek 1895; other names Beaudoin, Lemonde, Lamont). It has no parents attached, and its baptism source is the same FS image as s2.
