## 1. Woods

- The gravestone fixes Henry Sr.'s birth at **8 Jun 1794**. That fits all three censuses (30–39 in 1830, 40–49 in 1840, "53" in 1850 is loose). The FS tree's exact birth date therefore probably came from this stone or a copy of it, and is not independent evidence of a "Canada" birth.
- The 1848 remarriage gives a window for Eunice's death (after the 1840 census and before Feb 1848), so the youngest children of the first family are b. by c.1844. Ednas (b. c.1840) is Eunice's.
- Celtic relevance: none yet. The origin of the Woods line is still unknown.

## 3. Tool notes

- **Illinois Statewide Marriage Index** moved to `apps.ilsos.gov/isavital/marriagesrch.jsp`. Curl returns nothing. In Chrome, the results page is a POST to `/isavital/marriageSearch.do` with fields `groom`, `bride`, `county`, `submit`. Names are "Last, First" and a surname alone works. An in-page `fetch` POST loop works, but each query takes about 5 s, so run it in the background and poll a window variable.
- **Illinois Civil War Muster & Descriptive Rolls**: `apps.ilsos.gov/isaveterans/civilmustersrch.jsp`; type into the name field and press Return (setting the value by JS doesn't submit).
- Find a Grave: the `location` filter is ignored (as before), but `/cemetery/<id>/memorial-search?lastname=X` searches a single cemetery. Walnut Cemetery, Banner = 2168129.
- archive.org `_djvu.txt` downloads sometimes return nginx 500s; retry up to 3 times.
- BLM GLO advanced search hung on its loading spinner this session. WikiTree API answered "Limit exceeded".
